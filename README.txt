신상품 업데이트 파일 생성기 (로컬 웹앱)
========================================

실행 방법
---------
1) 파이썬이 설치되어 있어야 합니다 (기존에 옵션ver3.py / 자동업데이트파일생성(2026).py를
   실행하시던 환경이면 그대로 사용 가능합니다).
2) 이 폴더에서 아래 명령으로 필요한 패키지를 설치합니다.
       pip install -r requirements.txt
3) 아래 명령으로 앱을 실행합니다.
       streamlit run app.py
4) 자동으로 브라우저가 열립니다(안 열리면 터미널에 나오는 http://localhost:8501 주소로 접속).

사용 방법
---------
왼쪽 사이드바에서
  - 기린.xlsx, S파일(예: S20260820.xlsx) 두 개를 업로드 (필수)
  - 카테고리번호.xlsx는 업로드하지 않으면 assets 폴더의 기본 파일을 사용합니다.
  - 스마트스토어기본.xlsx(템플릿)를 업로드하면 N파일(스마트스토어 변환)까지 생성됩니다.
    업로드하지 않으면 이 단계만 건너뛰고 나머지는 정상적으로 생성됩니다.
  - 날짜/카테고리 행 번호 등은 필요하면 조정하세요.
'전체 파이프라인 실행' 버튼을 누르면 아래 순서로 처리됩니다.

  0단계 (수작업이었던 부분 자동화)
    기린.xlsx의 E,F,G열 -> S파일의 E,F,G열로 복사
    이 시점 상태를 곽충현.xlsx / 문정희(초안).xlsx 로 스냅샷 저장
      (현재는 "이름만 바꿔서 저장"하는 방식입니다 — 두 파일 각각 전용 가공 로직은
       추후 별도로 요청하신다고 하셨으니 그때 추가하면 됩니다)
    기린.xlsx의 AJ열 -> S파일의 AJ열로 복사 → 이 상태 = 예제.xlsx

  1단계 (기존 옵션ver3.py 로직)
    예제.xlsx -> 사이즈별 추가금 그룹 분리 + 가격 재계산 -> 새 기린.xlsx
    새 기린.xlsx -> 색상별 행 분리 + 상품명 정리 -> 날짜파일(예: 20260819.xlsx)
    새 기린.xlsx 그대로 -> 두두사사.xlsx 로 저장
    새 기린.xlsx의 E,F,G를 지운 사본 -> 다음 라운드용 S파일(예: S20260820.xlsx)
    새 기린.xlsx E열의 마지막 '|' 값(예: 6136) -> 카테고리번호.xlsx 29행 A열에 반영

  2단계 (기존 자동업데이트파일생성(2026).py 로직)
    두두사사.xlsx -> 김하늘/서송이/이지민/해피/김다혜/박미리/오토/오마베/최민기/
    현건주/목윤희/최은경/남부센/백종열/X날짜/백성희/모나마켓/문정희/이모이모
    (총 19개) 판매처별 파일 생성 + (템플릿 있으면) 스마트스토어 N파일 생성
    -> 카테고리번호.xlsx로 각 파일 E/F/G, N파일 B열 매핑
    -> 오토.xlsx 상품명 뒤에 매핑값 추가
    -> 금/오토/0/X날짜 파일 E,F,G 초기화

결과는 '1단계_예제생성' 폴더와 '2단계_판매처파일' 폴더로 나뉜 ZIP 파일로 한 번에
다운로드하거나, 개별 파일 버튼으로 하나씩 받을 수 있습니다.

참고 / 주의사항
----------------
- 기린 파일과 S파일의 행(상품) 수가 다르면 더 적은 쪽 행 수까지만 E,F,G/AJ를 복사하고
  로그에 경고를 남깁니다. 실제 운영에서는 두 파일이 같은 날짜의 같은 상품 목록이어야
  정확하게 동작합니다.
- 카테고리번호.xlsx 29행을 항상 고정 행으로 갱신하도록 되어 있습니다. 다른 행을 써야
  하는 경우가 생기면 화면의 '카테고리번호.xlsx 갱신 행 번호' 값을 바꿔서 실행하시면 됩니다.
- 곽충현.xlsx / 문정희(초안).xlsx 는 현재 "이름만 바꿔 저장"하는 자리표시 단계입니다.
  각 파일에 필요한 가공 규칙을 알려주시면 다음 업데이트에서 반영하겠습니다.
